# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥PREL40: Build data-rich apps in Microsoft Fabric
### Session description

Discover how Microsoft Fabric enables developers and AI coding agents to build enterprise-ready, data-rich applications faster. Using Rayfin, SQL database in Fabric, Power BI, and more, learn how to go from prompt to production with a unified platform for application data, analytics, and AI. See how operational and analytical workloads work together to simplify development, eliminate data silos, and deliver intelligent application experiences.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

1. Sign in to the lab virtual machine with the credentials shown in the Skillable instructions pane.
2. Follow the lab instructions in Skillable. They're also in [`docs/`](docs/README.md).

#### On your own

If you're learning at your own pace:

1. Set up GitHub Codespaces or your own machine with the [setup guide](docs/setup.md).
2. Follow the [self-guided workshop](https://aka.ms/ws?src=gh:microsoft/ignite26-PREL40/main/docs/self-guided/), the same lab adapted to your own GitHub Copilot, Microsoft Fabric, and Microsoft Foundry resources.

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Create a SQL database in Microsoft Fabric and build a Direct Lake semantic model with shared measures.
- Bootstrap, extend, and deploy a secure data-rich app with Rayfin and the GitHub Copilot app, using authentication, access policies, and private file storage.
- Add an AI-assisted feature with Microsoft Foundry through a server function, and monitor the deployed app in Microsoft Fabric.

### 💻 Technologies used

- Microsoft Fabric (SQL database in Fabric, Direct Lake semantic models, Fabric apps)
- Rayfin
- GitHub Copilot app
- Microsoft Foundry
